# 项目背景：葡萄酒管理系统

## 一句话定义

面向葡萄酒收藏者的本地优先酒窖管理系统，提供酒标识别、实体酒柜定位、出入库记录、适饮期提醒、价格快照、资产视图和采购消耗建议。

## 为什么做

葡萄酒收藏达到一定规模后，用户的问题从“查酒”变成“管理资产和消费节奏”：

- 忘记自己买过什么。
- 找不到酒放在哪个格子。
- 忘了什么时候该喝。
- 重复购买同类型酒。
- 一些酒过了适饮期。
- 不清楚整体库存结构。
- 不清楚购买成本和当前估值。
- 宴请时不知道该开什么。
- 采购时不知道该补什么、不该买什么。

## 用户画像

### 第一用户

拥有真实酒柜/酒窖，库存约 50-300 瓶，主要用于家庭自饮、朋友宴请、礼赠和收藏。

### 后续用户

- 高端家庭酒窖用户
- 葡萄酒爱好者
- 私宴/会所
- 小餐厅/酒吧
- 酒商的客户寄存管理

## 产品不是

- 不是葡萄酒社区。
- 不是评分平台。
- 不是电商导购。
- 不是自动爬价工具。
- 不是专业投资交易终端。

## 产品是

- 私人酒窖数据库。
- 酒柜位置地图。
- 出入库账本。
- 适饮期提醒器。
- 资产快照系统。
- 消耗与采购决策助手。

## 核心闭环

```text
录入 → 标准化 → 入库定位 → 出入库记录 → 适饮提醒 → 价值快照 → 消耗分析 → 采购建议
```

## 成功指标

MVP 成功不以“功能多”为标准，而以这些问题能否快速回答为标准：

1. 我现在有多少瓶酒？
2. 某一瓶在哪里？
3. 哪些酒未来 12 个月应该喝？
4. 哪些酒已经有过峰风险？
5. 最近喝掉/送出了哪些酒？
6. 我的库存结构是否失衡？
7. 我近期不应该继续买什么？
8. 数据是否可备份、可导出、可迁移？
