# Roadmap

## Phase 0：文档和规则

目标：建立项目背景、目录、开发规则、数据模型和任务拆分。

交付：

- README
- AGENTS.md
- PRD
- 数据模型
- API 草案
- Codex backlog

## Phase 1：本地库存核心

目标：能录入、定位、搜索、移动和出库。

交付：

- 后端项目骨架
- 数据库模型
- 基础 CRUD
- 库存 transaction 服务
- 酒柜和位置模型
- 基础测试

## Phase 2：前端 MVP

目标：普通用户可通过 Web UI 管理酒柜。

交付：

- 首页大屏
- 藏酒列表
- 入库表单
- 酒柜二维地图
- 酒瓶详情页
- 出库/移动交互

## Phase 3：适饮与资产

目标：形成决策价值。

交付：

- 适饮期设置
- 近期该喝列表
- 价格快照
- 资产总览
- 库存结构图

## Phase 4：导入导出和备份

目标：用户敢用、能迁移。

交付：

- CSV/Excel 导入导出
- 图片目录备份
- 数据库备份 zip
- 恢复流程

## Phase 5：AI 辅助录入

目标：降低录入成本。

交付：

- 酒标图片上传
- OCR/视觉识别为 draft
- 候选字段确认
- 人工纠错
- 别名库积累

## Phase 6：建议引擎

目标：回答“该喝什么、该买什么、不该买什么”。

交付：

- 适饮压力指数
- 消耗预测
- 采购缺口分析
- 不买清单
- 宴请推荐

## Phase 7：推广准备

目标：从个人工具演化为产品。

交付：

- 可选云备份
- 多设备同步
- 权限模型
- 隐私设置
- 商业化版本设计
