# ADR-0001：本地优先

## 状态

Accepted for MVP.

## 背景

系统涉及藏酒价值、购买价、送礼对象、酒柜位置和照片。这些数据对用户私密性较高。第一阶段目标是验证个人酒窖管理闭环，不需要账号、多租户和云同步。

## 决策

MVP 使用本地优先架构：

- 本地 API server。
- SQLite 数据库。
- 本地图片目录。
- 本地导入导出和备份。

## 后果

优点：

- 实现快。
- 隐私风险低。
- 用户可控。
- 方便个人迭代。

缺点：

- 多设备同步暂不支持。
- 远程访问暂不支持。
- 备份责任主要在用户本地。

## 未来迁移

后续可增加：

- 可选云备份。
- 局域网访问。
- 多设备同步。
- Postgres 云端版本。
