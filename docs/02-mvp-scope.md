# MVP 范围

## 必须做

### 库存核心

- Producer / Wine / Vintage / Bottle 分层模型。
- 多酒柜。
- 二维位置模型。
- 入库、出库、移动、饮用、送礼、损耗、盘点调整。
- 库存 transaction ledger。

### 基础 UI

- 首页大屏。
- 藏酒列表。
- 酒瓶详情。
- 酒柜地图。
- 入库表单。
- 出库/移动操作。
- 搜索与筛选。

### 图片

- 正标。
- 背标。
- 购买凭证。
- 开瓶照片。
- 本地路径与 hash。

### 适饮

- 手动设置适饮窗口。
- 系统规则建议。
- 置信度。
- 近期该喝列表。

### 资产

- 买入价。
- 当前价格快照。
- 来源与日期。
- 当前估值汇总。

### 导入导出

- CSV/Excel 导入。
- CSV/Excel 导出。
- 本地备份 zip。

## 暂不做

- 自动大规模 WS 爬虫。
- 支付。
- 用户注册登录。
- 多租户。
- 复杂权限。
- 社区评论。
- 电商跳转。
- 专业交易估值。
- 自动下单。

## 以后可做

- 云备份。
- 多设备同步。
- NFC/二维码标签。
- 温湿度传感器。
- 宴请计划器。
- 采购模拟器。
- 保险/资产报告。
- 小 B 托管版。
