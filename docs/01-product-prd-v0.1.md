# PRD v0.1

## 版本目标

构建一个可本地运行的私人酒窖管理 MVP，支持从录入到出库的完整闭环，并提供基础适饮与库存结构分析。

## 用户故事

### US-001：录入新酒

作为用户，我希望可以录入一瓶酒的名称、年份、容量、购买价、来源、照片和存放位置，以便未来能找到并追踪它。

验收标准：

- 支持手动录入。
- 支持上传正标、背标、购买凭证图片。
- 可以选择或创建酒柜位置。
- 保存前展示确认页面。

### US-002：查找酒

作为用户，我希望按酒名、中文名、年份、国家、产区、类型、标签、位置搜索，以便快速找到目标酒。

验收标准：

- 支持模糊搜索。
- 支持中文、英文别名。
- 搜索结果显示位置、数量、适饮状态、估值。

### US-003：酒柜地图

作为用户，我希望看到酒柜二维格子图，以便知道每个格子放了什么。

验收标准：

- 支持多酒柜。
- 支持按行列显示格子。
- 点击格子查看瓶列表。
- 支持空位、高价值酒、适饮酒的视觉提示。

### US-004：出库

作为用户，我希望记录喝掉、送礼、卖出、损耗和移动，以便库存历史可追溯。

验收标准：

- 出库必须生成 transaction。
- 出库后 bottle 状态变化。
- 历史详情仍可查询。
- 不允许无记录删除库存。

### US-005：适饮提醒

作为用户，我希望看到哪些酒进入适饮期、哪些有过峰风险，以便合理安排饮用。

验收标准：

- 每个 vintage 可设置 drink_from、drink_to。
- 可以手动覆盖系统建议。
- 展示当前状态：过早、进入适饮、巅峰、后段、过峰风险、未知。
- 展示置信度。

### US-006：价格快照

作为用户，我希望记录某酒在某时间点的市场参考价格，以便理解资产变化。

验收标准：

- 支持手动录入价格。
- 支持记录来源、币种、地区、税费说明、日期、置信度。
- 不承诺价格自动准确。
- 不实现大规模爬虫。

### US-007：大屏

作为用户，我希望在首页看到酒窖整体情况，以便快速决策。

验收标准：

- 总瓶数。
- 酒柜占用率。
- 购买总成本。
- 当前估值。
- 未来 12 个月建议饮用数。
- 过峰风险数。
- 按类型、国家、产区、价格带分布。

## 非功能要求

- 本地可运行。
- 数据可导出。
- 图片本地存储。
- 默认不上传云端。
- 所有重要写操作有确认或可追溯记录。
- UI 以中文为主。
