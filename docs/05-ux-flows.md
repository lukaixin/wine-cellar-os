# UX 流程

## 流程 1：新酒入库

```text
入口：首页/藏酒页 → 新增入库
1. 选择录入方式：手动 / 拍照识别 / 批量导入
2. 填写或确认酒庄、酒款、年份、容量
3. 填写购买信息：日期、价格、币种、来源、数量
4. 上传图片：正标、背标、购买凭证
5. 选择位置：酒柜、行、列、层、箱
6. 设置标签：送礼、纪念、快喝、请客稳妥等
7. 保存前确认
8. 系统创建 Bottle 和 purchase_in transaction
```

关键规则：AI 识别结果只能填充草稿，不直接入库。

## 流程 2：找酒

```text
入口：搜索框 / 藏酒列表 / 酒柜地图
1. 输入中文名、英文名、年份、别名
2. 结果列表显示：酒名、年份、位置、状态、适饮状态、估值
3. 点击进入详情
4. 可执行：移动、喝掉、送礼、编辑、添加照片、记录品鉴
```

## 流程 3：喝掉一瓶

```text
1. 打开 Bottle 详情
2. 点击“喝掉”
3. 填写饮用日期、场景、搭配、评价、备注
4. 上传开瓶照，可选
5. 确认后创建 drink_out transaction
6. Bottle 状态改为 drunk，位置清空
```

## 流程 4：送礼

```text
1. 选择 Bottle
2. 点击“送礼”
3. 填写对象、场合、日期、备注
4. 确认后创建 gift_out transaction
5. Bottle 状态改为 gifted，位置清空
```

隐私规则：送礼对象属于敏感信息，本地保存，默认不导出公开报告。

## 流程 5：盘点

```text
1. 进入盘点模式
2. 选择酒柜
3. 按格子逐项确认
4. 标记：存在 / 不存在 / 位置不符 / 多出一瓶
5. 生成盘点差异报告
6. 用户确认后生成 stocktake_adjustment transactions
```

## 流程 6：今晚喝什么

```text
1. 选择场景：自饮 / 请客 / 配餐 / 快过峰 / 便宜点 / 有故事
2. 系统根据库存、适饮期、价格、标签过滤
3. 展示 3-5 个建议，并说明原因
4. 用户选择后可直接进入“喝掉”流程
```

MVP 可先做规则推荐，不做复杂机器学习。
